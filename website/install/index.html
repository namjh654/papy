설치 방법

운영체제별로 설치하고 처음 실행하는 방법입니다. 파일은 다운로드 페이지에서 받으세요.

  • Windows
  • macOS
  • Linux
  • 업데이트·삭제
보안 경고가 뜨는 이유: Papy 는 아직 운영체제 개발자 인증서로 서명되지 않았습니다. 파일은 공개 소스에서 GitHub Actions 로 빌드되며, 반드시 공식 다운로드나 GitHub Releases에서만 받으세요.

Windows

  1. Papy_…_x64-setup.exe 를 받아 실행합니다.
  2. “Windows의 PC 보호” 창이 나오면 추가 정보 → 실행을 누릅니다.
  3. 설치 마법사를 따라 설치합니다. 관리자 권한 없이 현재 사용자에게 설치됩니다.
  4. 시작 메뉴에서 Papy 를 실행합니다.

Papy 는 Windows 에 기본 포함된 Microsoft Edge WebView2 를 사용합니다. 없으면 설치 프로그램이 자동으로 내려받습니다(이때만 인터넷 필요).

macOS

방법 1: 터미널 한 줄 (권장)

응용 프로그램 → 유틸리티 → 터미널을 열고 아래를 붙여 넣습니다. Mac 종류(Apple Silicon·Intel)에 맞는 최신 정식판을 받아 응용 프로그램 폴더에 넣습니다.

curl -fsSL {{site}}/install.sh | sh

이렇게 받은 앱은 보안 경고 없이 바로 열립니다. 업데이트도 같은 명령을 다시 실행하면 됩니다. 스크립트 내용은 여기에서 미리 볼 수 있습니다.

방법 2: .dmg 로 설치

  1. Mac 종류에 맞는 .dmg 를 받습니다 — Apple Silicon 은 aarch64, Intel 은 x64. (Apple 메뉴 → 이 Mac에 관하여에서 칩 확인)
  2. .dmg 를 열고 Papy 를 응용 프로그램 폴더로 끌어 놓습니다.
  3. 처음 실행할 때 “Apple은 ‘Papy’에 악성 코드가 없음을 확인할 수 없습니다” 창이 나오면 휴지통으로 이동이 아니라 완료를 누르고:
    • macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안을 열어 아래쪽 “Papy이(가) 차단되었습니다” 옆의 그래도 열기를 누른 뒤, 다시 실행해 열기를 누르고 Mac 암호를 넣습니다.
    • macOS 14 이하: Finder 에서 Papy 를 control+클릭 → 열기 → 열기.
  4. 그래도 열기가 보이지 않거나 “손상되었기 때문에 열 수 없습니다”가 나오면 터미널에서 다음을 실행한 뒤 다시 엽니다. 
    xattr -dr com.apple.quarantine /Applications/Papy.app

Linux

AppImage (설치 없이 실행)

chmod +x Papy_*_amd64.AppImage
./Papy_*_amd64.AppImage

실행되지 않으면 FUSE 가 필요할 수 있습니다: Ubuntu 22.04 이상은 sudo apt install libfuse2 (24.04 는 libfuse2t64).

Debian · Ubuntu (.deb)

sudo apt install ./Papy_*_amd64.deb

Fedora · openSUSE (.rpm)

sudo dnf install ./Papy-*.x86_64.rpm

패키지로 설치하면 필요한 WebKitGTK 라이브러리가 함께 설치되고, 앱 메뉴에 Papy 가 추가됩니다.

삭제

운영체제방법
Windows설정 → 앱 → 설치된 앱 → Papy → 제거
macOS응용 프로그램 폴더에서 Papy 를 휴지통으로 이동
LinuxAppImage 파일 삭제, 또는 sudo apt remove papy / sudo dnf remove papy
