PDF·한글·Word 문서를
내 컴퓨터에서 보고 고치고, 무료로.

Papy(페이피)는 PDF·HWP·HWPX·DOCX·DOC 문서를 열고 편집하는 소스 공개 문서 앱입니다. 보기 모드와 편집 모드를 한 번에 바꾸고, 저장·다른 이름으로 저장·형식 변환까지 오프라인으로 합니다. 회원가입·광고·서버 업로드는 없습니다.

무료 다운로드 설치 방법 GitHub 소스 보기
v0.4.1 이 나왔습니다. 앱 아이콘을 새로 바꿨습니다. v0.4.0 에서는 한글 엔진을 새 버전으로 올리고, 한글 ↔ 워드 변환 배치를 다듬었습니다. 각주 많은 Word 문서와 큰 표 한글 문서를 훨씬 빨리 엽니다. 형식을 바꿔 저장할 때는 줄바꿈·쪽 수가 달라질 수 있음을 미리 알려 드립니다. 다운로드에서 받으세요.

Papy 의 약속

오프라인 우선

문서 본문을 어떤 서버로도 보내지 않습니다. 인터넷이 없어도 열람합니다.

무계정·무광고

로그인, 광고, 사용 추적이 없습니다. 설치하면 바로 씁니다.

보기·편집 전환

읽을 때는 보기 모드, 고칠 때는 Ctrl/⌘+E 로 편집 모드. 문서마다 따로 앱을 열 필요가 없습니다.

저장·변환

원래 형식으로 저장하거나 HWP ↔ HWPX ↔ DOCX ↔ PDF 로 바꿔 저장합니다. 옛 Word(.doc)도 열어서 바꿔 저장합니다.

한글 문서 우선

한국에서 많이 쓰는 HWP·HWPX 를 한컴오피스 없이 열고 고칩니다.

가볍고 빠르게

Rust 문서 엔진과 Tauri 로 만들어 설치 파일이 작고 빠르게 뜹니다.

여러 운영체제

Windows·macOS·Linux 데스크톱부터, 이후 Android·iOS 로 넓힙니다.

소스 공개

모든 코드가 GitHub 에 공개되어 있어 누구나 확인하고 기여할 수 있습니다(PolyForm Noncommercial).

요금·라이선스

정말 무료인가요?

네. 개인·학습·연구·비영리 등 비상업적 용도라면 무료입니다. 광고·구독·유료 기능도 없습니다.

회사 업무에도 쓸 수 있나요?

회사 업무처럼 상업적으로 쓰려면 별도 상용 라이선스가 필요합니다. 문의해 주세요.

라이선스는 무엇인가요?

소스 코드와 배포 파일 모두 PolyForm Noncommercial 1.0.0 을 따릅니다.

  • 비상업적 목적의 사용·수정·재배포: 허용
  • 상업적 이용: 별도 상용 라이선스 필요

문서·형식

한컴오피스 없이 HWP 파일을 열 수 있나요?

네. HWP(5.x)와 HWPX 를 한컴오피스 없이 열고, 글자와 서식을 고쳐 저장합니다. 표·그림·머리말은 고급 편집으로 고칩니다.

Word(DOCX·DOC) 문서도 되나요?
  • DOCX: 열어서 고치고 DOCX 로 저장하거나 HWP·HWPX·PDF 로 바꿔 저장합니다.
  • DOC(97–2003): 열어서 고칠 수 있고, 저장은 DOCX·HWP·HWPX·PDF 로 합니다.
  • 그림·도형·묶음 도형·차트·머리말·꼬리말·각주·번호 목록이 옮겨집니다.

아직 옮기지 못하는 요소(OLE 개체, .doc 의 떠 있는 도형 등)가 있으면 열 때 알려 드립니다.

한글 ↔ 워드로 바꾸면 모양이 그대로인가요?

내용은 그대로 옮기지만, 한글과 Word 는 줄을 나누고 쪽을 나누는 규칙이 달라 줄바꿈·쪽 수가 조금 달라질 수 있습니다. 그래서 형식을 바꿔 저장하기 전과 Word 문서를 열 때 미리 알려 드립니다. 중요한 문서는 원본을 따로 보관하세요.

PDF 로 내보낼 수 있나요?

네. HWP·HWPX·DOCX·DOC 문서를 PDF 로 내보냅니다. PDF 는 열어서 형광펜·메모·펜·글자 고치기·쪽 회전과 삭제를 할 수 있습니다.

파워포인트·엑셀 파일은 언제 되나요?

문서 3종(한글·워드·PDF)을 안정화한 다음 PPT·PPTX, 이어서 XLS·XLSX 순서로 추가합니다.

개인정보·보안

내 문서가 인터넷으로 전송되나요?

아니요. 문서는 내 컴퓨터 안에서만 처리됩니다. 앱이 인터넷을 쓰는 경우는 (추가될 경우) 새 버전 확인처럼 명시된 목적뿐입니다. 자세한 내용은 개인정보 처리방침을 보세요.

설치할 때 보안 경고가 떠요.

Papy 는 아직 코드 서명을 하지 않아 Windows·macOS 가 처음 실행할 때 경고를 보여 줍니다. 공식 다운로드에서 받은 파일이라면 안전하게 열 수 있습니다. 운영체제별 해결 방법은 설치 방법에 있습니다.

설치·기기

어떤 운영체제에서 쓸 수 있나요?

Windows·macOS(Apple Silicon·Intel)·Linux(.deb·.rpm·AppImage)를 지원합니다. 다운로드에서 접속한 운영체제에 맞는 파일을 먼저 보여 드립니다.

새 버전은 어떻게 받나요?

새 버전을 받아 같은 방법으로 설치하면 덮어씁니다. 자동 업데이트는 아직 없습니다.

휴대폰에서도 쓸 수 있나요?

지금은 데스크톱만 배포합니다. 같은 엔진으로 Android·iOS 앱을 준비하고 있습니다.
