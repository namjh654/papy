PDF와 한글 문서를
내 컴퓨터에서 바로, 무료로.

Papy(페이피)는 PDF와 HWP/HWPX 문서를 우선 지원하는 오픈소스 문서 뷰어입니다. 회원가입·광고·서버 업로드 없이, 내가 고른 파일만 오프라인으로 엽니다.

무료 다운로드 설치 방법 GitHub 소스 보기
초기 개발 단계입니다. 지금 배포되는 앱은 설치·실행 확인용이며 아직 문서를 열 수 없습니다. 기능이 검증되는 대로 이 페이지와 사용법에 표시합니다.

Papy 의 약속

오프라인 우선

문서 본문을 어떤 서버로도 보내지 않습니다. 인터넷이 없어도 열람합니다.

무계정·무광고

로그인, 광고, 사용 추적이 없습니다. 설치하면 바로 씁니다.

한글 문서 우선

PDF 와 함께 한국에서 많이 쓰는 HWPX·HWP 열람을 핵심 목표로 합니다.

가볍고 빠르게

Rust 문서 엔진과 Tauri 로 만들어 설치 파일이 작고 빠르게 뜹니다.

여러 운영체제

Windows·macOS·Linux 데스크톱부터, 이후 Android·iOS 로 넓힙니다.

오픈소스

모든 코드가 GitHub 에 공개되어 있고 누구나 확인하고 기여할 수 있습니다.

자주 묻는 질문

정말 무료인가요?

네. 오픈소스로 개발되며 유료 기능·광고·구독이 없습니다.

내 문서가 인터넷으로 전송되나요?

아니요. 문서는 내 컴퓨터 안에서만 처리됩니다. 앱이 인터넷을 쓰는 경우는 (추가될 경우) 새 버전 확인처럼 명시된 목적뿐입니다. 자세한 내용은 개인정보 처리방침을 보세요.

한컴오피스 없이 HWP 파일을 열 수 있나요?

그것이 Papy 의 목표입니다. HWPX 를 먼저 지원하고, HWP(5.x)는 기술 검증 후 지원 범위를 알려 드립니다.

휴대폰에서도 쓸 수 있나요?

데스크톱 엔진이 안정되면 같은 엔진으로 Android·iOS 앱을 만들 예정입니다.
