PDF·한글·Word 문서를
내 컴퓨터에서 보고 고치고, 무료로.

Papy(페이피)는 PDF·HWP·HWPX·DOCX·DOC 문서를 열고 편집하는 소스 공개 문서 앱입니다. 보기 모드와 편집 모드를 한 번에 바꾸고, 저장·다른 이름으로 저장·형식 변환까지 오프라인으로 합니다. 회원가입·광고·서버 업로드는 없습니다.

무료 다운로드 설치 방법 GitHub 소스 보기
v0.3.3 이 나왔습니다. 2단 문서의 단 나누기, 첫 줄 들여쓰기, 칸 대각선을 옮기고 한글 → DOCX 변환의 쪽 배치를 원본에 더 가깝게 맞췄습니다. v0.3.1 부터 내보낸 PDF 에서 글 찾기·복사가 됩니다. 다운로드에서 받으세요.

Papy 의 약속

오프라인 우선

문서 본문을 어떤 서버로도 보내지 않습니다. 인터넷이 없어도 열람합니다.

무계정·무광고

로그인, 광고, 사용 추적이 없습니다. 설치하면 바로 씁니다.

보기·편집 전환

읽을 때는 보기 모드, 고칠 때는 Ctrl/⌘+E 로 편집 모드. 문서마다 따로 앱을 열 필요가 없습니다.

저장·변환

원래 형식으로 저장하거나 HWP ↔ HWPX ↔ DOCX ↔ PDF 로 바꿔 저장합니다. 옛 Word(.doc)도 열어서 바꿔 저장합니다.

한글 문서 우선

한국에서 많이 쓰는 HWP·HWPX 를 한컴오피스 없이 열고 고칩니다.

가볍고 빠르게

Rust 문서 엔진과 Tauri 로 만들어 설치 파일이 작고 빠르게 뜹니다.

여러 운영체제

Windows·macOS·Linux 데스크톱부터, 이후 Android·iOS 로 넓힙니다.

소스 공개

모든 코드가 GitHub 에 공개되어 있어 누구나 확인하고 기여할 수 있습니다(PolyForm Noncommercial).

자주 묻는 질문

정말 무료인가요?

개인·학습·연구·비영리 등 비상업적 용도라면 무료입니다. 광고·구독·유료 기능도 없습니다. 회사 업무 등 상업적으로 쓰려면 문의해 주세요.

라이선스는 무엇인가요?

소스 코드와 배포 파일 모두 PolyForm Noncommercial 1.0.0 을 따릅니다. 비상업적 목적의 사용·수정·재배포는 허용되고, 상업적 이용은 허용되지 않습니다.

내 문서가 인터넷으로 전송되나요?

아니요. 문서는 내 컴퓨터 안에서만 처리됩니다. 앱이 인터넷을 쓰는 경우는 (추가될 경우) 새 버전 확인처럼 명시된 목적뿐입니다. 자세한 내용은 개인정보 처리방침을 보세요.

한컴오피스 없이 HWP 파일을 열 수 있나요?

네. HWP(5.x)와 HWPX 를 한컴오피스 없이 열고, 글자와 서식을 고쳐 저장할 수 있습니다. 표·그림·머리말은 고급 편집으로 고칩니다.

Word(DOCX·DOC) 문서도 되나요?

DOCX 를 열어 고치고 다시 DOCX 로 저장하거나, HWP·HWPX·PDF 로 바꿔 저장할 수 있습니다. 그림·도형·묶음 도형·차트·머리말·꼬리말·각주·번호 목록이 옮겨집니다. 옛 Word(.doc, 97–2003)도 열어 고칠 수 있고, 저장은 DOCX·HWP·HWPX·PDF 로 합니다. 아직 옮기지 못하는 요소(OLE 개체, .doc 의 떠 있는 도형 등)가 있으면 열 때 알려 드립니다. 원본은 따로 두세요.

휴대폰에서도 쓸 수 있나요?

데스크톱 엔진이 안정되면 같은 엔진으로 Android·iOS 앱을 만들 예정입니다.
