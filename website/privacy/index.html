개인정보 처리방침

시행일: 2026년 11월 13일

Papy 앱

  • 회원가입·로그인이 없으며 이름·이메일 등 개인정보를 받지 않습니다.
  • 문서 본문, 문서에서 추출한 글, 파일 경로를 외부로 보내거나 로그에 기록하지 않습니다.
  • 광고·분석·추적 SDK 를 넣지 않습니다.
  • 사용자가 직접 고른 파일만 읽습니다. 최근 문서 목록(추가 시)은 내 기기에만 저장되며 앱에서 지울 수 있습니다.
  • 인터넷 연결은 새 버전 확인 등 명시된 목적에만 사용하며(추가 시 이 문서에 적습니다), 문서 열람에는 필요하지 않습니다.

AI 도우미 플러그인 (선택)

  • 플러그인을 설치하고 대화창을 쓸 때만 동작합니다. 설치하지 않으면 위 "Papy 앱" 내용이 그대로 적용됩니다.
  • 설치할 때 GitHub(github.com)에서 플러그인 파일을 내려받습니다.
  • 대화 상대로 고른 서비스에만 내 질문과, AI 가 도구로 읽은 문서 부분(문단 글·쪽 글·찾기 결과, 파일 이름·쪽 수)을 보냅니다: Anthropic(Claude), OpenAI(ChatGPT), Google(Gemini), 또는 Claude Code·Codex·Gemini CLI 를 거쳐 그 회사. 보낸 내용은 그 회사의 개인정보 처리방침에 따라 처리됩니다. 외부 서비스로 처음 보내기 전에 문서마다 묻습니다.
  • Ollama 를 고르면 내 컴퓨터 안에서만 주고받습니다.
  • API 키는 운영체제 키체인(macOS 키체인, Windows 자격 증명 관리자, Linux 비밀 서비스)에만 저장하며 Papy 개발자에게 보내지 않습니다. 대화 내용은 앱을 닫으면 사라지고 따로 저장하지 않습니다.
  • MCP 서버로 쓰면, 그 서버를 부른 AI 앱(예: Claude 데스크톱)이 읽은 내용을 그 앱의 서비스로 보냅니다.

이 웹사이트

  • 쿠키와 광고를 쓰지 않습니다.
  • 방문 수는 쿠키 없는 Vercel Web Analytics 로 셉니다. 방문한 페이지 주소, 들어온 경로(참조 페이지), 국가, 브라우저·운영체제·기기 종류만 모으며, 개인을 알아보거나 다른 사이트까지 따라가지 않습니다. 같은 방문자인지는 IP 주소 등으로 만든 값으로 하루 동안만 구분하고 IP 주소는 저장하지 않습니다.
  • 사이트는 Vercel 에서 호스팅되며, Vercel 은 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다.
  • 문의 폼에 적은 유형·이름(선택)·이메일·제목·내용은 이메일 발송 서비스 Resend 를 거쳐 개발자 메일함으로만 전달됩니다. 사이트나 별도 데이터베이스에 저장하지 않으며, 답변과 문의 처리 외의 목적으로 쓰지 않습니다. 삭제를 원하면 같은 경로로 요청해 주세요.
  • 다운로드·개발자·통계 페이지는 최신 설치 파일·진행 중인 작업 목록·다운로드 횟수를 보여 주기 위해 브라우저에서 GitHub API(api.github.com)에, CI 상태 배지를 위해 github.com 에 요청합니다. 설치 파일은 GitHub 에서 내려받습니다.
