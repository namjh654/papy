개인정보 처리방침

시행일: 2026년 11월 3일

Papy 앱

  • 회원가입·로그인이 없으며 이름·이메일 등 개인정보를 받지 않습니다.
  • 문서 본문, 문서에서 추출한 글, 파일 경로를 외부로 보내거나 로그에 기록하지 않습니다.
  • 광고·분석·추적 SDK 를 넣지 않습니다.
  • 사용자가 직접 고른 파일만 읽습니다. 최근 문서 목록(추가 시)은 내 기기에만 저장되며 앱에서 지울 수 있습니다.
  • 인터넷 연결은 새 버전 확인 등 명시된 목적에만 사용하며(추가 시 이 문서에 적습니다), 문서 열람에는 필요하지 않습니다.

이 웹사이트

  • 쿠키, 광고, 분석 도구를 사용하지 않습니다.
  • 사이트는 Vercel 에서 호스팅되며, Vercel 은 서비스 운영을 위해 접속 기록(IP 주소 등)을 처리할 수 있습니다.
  • 다운로드 페이지는 최신 설치 파일 목록을 보여 주기 위해 브라우저에서 GitHub API(api.github.com)에 요청합니다. 설치 파일은 GitHub 에서 내려받습니다.
