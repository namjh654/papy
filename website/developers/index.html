가장 쉬운 기여 — 웹에서 바로 수정

  1. 이 사이트 모든 페이지 아래의 “이 페이지 수정 제안”을 누릅니다.
  2. GitHub 편집기에서 고친 뒤 Commit changes… → Propose changes 를 누릅니다.
  3. GitHub 가 Fork 와 브랜치를 자동으로 만들고 Pull Request 화면으로 안내합니다. Create pull request 를 누르면 끝입니다.

코드 없이 의견만 있다면 Issue 나 문의로 알려 주세요. 처음이라면 good first issue 라벨부터 보세요.

Pull Request 절차

  1. Fork 후 내 저장소를 받습니다. 
    git clone https://github.com/<내-계정>/papy.git
cd papy
git remote add upstream {{repo}}.git
  2. 최신 main 에서 브랜치를 만듭니다 — feature/*, fix/*, docs/*. 
    git fetch upstream
git switch -c fix/pdf-zoom upstream/main
  3. 고친 영역의 검증을 돌립니다 (아래 표). CI 도 같은 명령을 실행합니다.
  4. 커밋하고 push 한 뒤 Compare & pull request 를 누릅니다. 
    git push -u origin fix/pdf-zoom
  5. PR 템플릿의 체크리스트와 테스트 결과를 채우면 리뷰 후 병합합니다.
바꾼 곳로컬 검증 명령
engine/cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace
apps/desktop/pnpm --filter @papy/desktop typecheck · pnpm desktop:dev
website/pnpm --filter @papy/website build
apps/mobile/cd apps/mobile && scripts/orca.sh check

규칙 전체는 CONTRIBUTING.md 에 있습니다. 문서 본문·개인 경로를 로그에 남기지 않기, 엔진이 UI 에 의존하지 않기가 핵심입니다.
