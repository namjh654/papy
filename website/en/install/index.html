Installation

How to install Papy and open it for the first time on each operating system. Get the files from the download page.

  • Windows
  • macOS
  • Linux
  • Update and uninstall
Why you may see a security warning: Papy is not yet signed with an operating-system developer certificate. The files are built from public source on GitHub Actions. Only download them from the official download page or GitHub Releases.

Windows

  1. Download and run Papy_…_x64-setup.exe.
  2. If “Windows protected your PC” appears, click More info → Run anyway.
  3. Follow the setup wizard. Papy installs for the current user without administrator rights.
  4. Start Papy from the Start menu.

Papy uses Microsoft Edge WebView2, which comes with Windows. If it is missing, the installer downloads it automatically (the only time an internet connection is needed).

macOS

Option 1: one line in Terminal (recommended)

Open Applications → Utilities → Terminal and paste the line below. It downloads the latest stable build for your Mac (Apple Silicon or Intel) into the Applications folder.

curl -fsSL {{site}}/install.sh | sh

An app installed this way opens without the security prompt. Run the same command again to update. You can read the script here first.

Option 2: install from the .dmg

  1. Download the .dmg for your Mac: aarch64 for Apple Silicon, x64 for Intel. (Check your chip under Apple menu → About This Mac.)
  2. Open the .dmg and drag Papy into the Applications folder.
  3. If “Apple could not verify ‘Papy’ is free of malware” appears the first time, click Done (not Move to Trash), then:
    • macOS 15 or later: open System Settings → Privacy & Security, click Open Anyway next to “Papy was blocked” at the bottom, open Papy again, click Open and enter your Mac password.
    • macOS 14 or earlier: in Finder, control-click Papy → Open → Open.
  4. If Open Anyway does not appear, or you see “Papy is damaged and can’t be opened”, run the following in Terminal and open it again. 
    xattr -dr com.apple.quarantine /Applications/Papy.app

Linux

AppImage (runs without installing)

chmod +x Papy_*_amd64.AppImage
./Papy_*_amd64.AppImage

If it does not start, you may need FUSE: on Ubuntu 22.04 or later run sudo apt install libfuse2 (libfuse2t64 on 24.04).

Debian · Ubuntu (.deb)

sudo apt install ./Papy_*_amd64.deb

Fedora · openSUSE (.rpm)

sudo dnf install ./Papy-*.x86_64.rpm

Installing a package also installs the WebKitGTK libraries Papy needs and adds Papy to your application menu.

Update and uninstall

Update

Download the new version and install it the same way; it replaces the old one. Automatic updates are not available yet. Coming later

Uninstall

OSHow
WindowsSettings → Apps → Installed apps → Papy → Uninstall
macOSMove Papy from the Applications folder to the Trash
LinuxDelete the AppImage file, or run sudo apt remove papy / sudo dnf remove papy
