Privacy policy

Effective date: November 13, 2026

This is a translation. If it differs from the Korean version, the Korean version applies.

The Papy app

  • There is no sign-up or sign-in, and the app does not collect personal information such as your name or email.
  • Document contents, text extracted from documents and file paths are never sent anywhere or written to logs.
  • No advertising, analytics or tracking SDKs are included.
  • Papy only reads files you choose. The recent documents list stays on your device, and you can clear it in the app.
  • The internet is used only for clearly stated purposes such as checking for a new version (if added, it will be listed here). Viewing documents never needs it.

AI assistant plugin (optional)

  • This applies only when you install the plugin and use the chat. Without it, "The Papy app" above applies unchanged.
  • Installing downloads the plugin file from GitHub (github.com).
  • Your questions, and the parts of the document the assistant reads with its tools (paragraph text, page text, search results, file name and page count), are sent only to the service you choose: Anthropic (Claude), OpenAI (ChatGPT), Google (Gemini), or that company through Claude Code, Codex or Gemini CLI. They are handled under that company's privacy policy. Papy asks once per document before the first send to an outside service.
  • With Ollama everything stays on your computer.
  • API keys are stored only in your operating system's keychain (macOS Keychain, Windows Credential Manager, Linux Secret Service) and are never sent to the Papy developer. Chats disappear when you close the app and are not saved.
  • When used as an MCP server, the AI app that calls it (for example Claude Desktop) sends what it reads to its own service.

This website

  • No cookies or ads are used.
  • Visits are counted with cookie-free Vercel Web Analytics. It collects only the page address, the referring page, country, and browser, operating system and device type. It does not identify you or follow you to other sites. Visitors are told apart for one day only, using a value derived from the IP address and other request data; the IP address itself is not stored.
  • The site is hosted on Vercel, which may process access logs (such as IP addresses) to run the service.
  • The topic, name (optional), email, subject and message you enter in the contact form are delivered only to the developer’s mailbox through the email service Resend. They are not stored on the site or in any database, and are used only to reply to and handle your inquiry. To have them deleted, ask through the same form.
  • The download and developers and statistics pages ask the GitHub API (api.github.com) from your browser for the latest installers, open work and download counts, and load CI status badges from github.com. Installers are downloaded from GitHub.

Questions

Please ask through GitHub Issues.
