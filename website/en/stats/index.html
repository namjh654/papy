How it is counted

  • Repeated downloads by the same person are counted each time, so this is not the number of users.
  • Downloads from the download page, GitHub, the macOS Terminal install (.app.tar.gz) and winget are all included.
  • Pre-releases (rc) are counted too and listed separately in the version table.
