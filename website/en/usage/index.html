Getting started

  1. Install Papy by following the installation guide, then open it.
  2. The start screen appears right away, with no sign-in or sign-up.
  3. Documents open in view mode. Switch to edit mode only when you want to make changes.

Opening documents Next release

  • Choose a file: the Open button or Ctrl+O.
  • Drag and drop: drop a file onto the Papy window.
  • Double-click: once installed, PDF, HWP, HWPX and DOCX files can open in Papy.
  • Recent documents: reopen them from the start screen. The list stays on your computer and you can clear it at any time.
  • Password-protected files: Papy asks for the password of protected PDF and HWP files. Passwords are never stored.

Papy only reads the files you choose. It does not scan other folders or upload files anywhere.

Edit mode Next release

Use the Edit button in the toolbar or Ctrl+E to switch between view mode and edit mode. HWP, HWPX and DOCX files are edited like in a word processor.

Advanced editing (HWP, HWPX)

Click Advanced editing at the right of the format bar in edit mode to open an editor for tables and cells, images and objects, headers and footers, footnotes, and find and replace. Click Apply to bring the changes into the document, then save as usual with Ctrl+S. The editor works offline too.

Editing PDFs Next release

A toolbar appears when you switch a PDF to edit mode.

  • Highlight, underline, strikethrough: pick a tool and drag over the text.
  • Pen: draw freely, with your choice of color and width.
  • Text box and note: click where you want it and type (Korean is supported).
  • Pages: rotate, move forward or back, and delete pages.
  • Undo with Ctrl+Z; press Esc to put the tool down.

Changing text that is already in a PDF is not supported yet.

Saving and converting Next release

  • Save Ctrl+S: overwrites the original file. Papy writes to a temporary file first, so the original stays intact if something goes wrong.
  • Save as Ctrl+Shift+S: choose a new location and format.
  • Export: save in another format from the export menu in the toolbar.
  • Unsaved changes are marked on screen, and Papy asks whether to save when you close.

Troubleshooting

The app does not open

Check the security warning steps for your operating system in the installation guide.

I found a bug / I have an idea

Please open a GitHub Issue. Describe the symptoms only; do not attach personal documents.
