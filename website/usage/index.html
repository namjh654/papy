사용법

Papy 로 문서를 여는 방법과 지원 범위입니다. 표시가 사용 가능인 것만 지금 버전에서 동작합니다.

  • 시작하기
  • 문서 열기
  • 보기·이동
  • 지원 범위
  • 문제 해결
현재 버전은 미리보기입니다. 앱 설치·실행과 엔진 연결만 확인할 수 있고, 문서 열기 기능은 개발 중입니다.

시작하기 사용 가능

  1. 설치 방법대로 설치하고 Papy 를 실행합니다.
  2. 로그인·회원가입 없이 바로 시작 화면이 나옵니다.
  3. 화면에 표시되는 엔진 버전으로 설치된 버전을 확인할 수 있습니다.

문서 열기 준비 중

  • 파일 선택: 열기 버튼(또는 Ctrl/⌘+O)으로 문서를 고릅니다.
  • 끌어 놓기: 파일을 Papy 창으로 끌어다 놓습니다.
  • 최근 문서: 최근에 연 문서를 시작 화면에서 다시 엽니다. 목록은 내 컴퓨터에만 저장되고 언제든 지울 수 있습니다.

Papy 는 사용자가 직접 고른 파일만 읽습니다. 다른 폴더를 뒤지거나 파일을 어딘가로 올리지 않습니다.
