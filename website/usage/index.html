아래 단축키의 Ctrl 은 macOS 에서 ⌘ 입니다.

시작하기

  1. 설치 방법대로 설치하고 Papy 를 실행합니다.
  2. 로그인·회원가입 없이 바로 시작 화면이 나옵니다.
  3. 문서를 열면 보기 모드로 시작합니다. 고칠 때만 편집 모드로 바꿉니다.

문서 열기 v0.3.0

  • 파일 선택: 열기 버튼 또는 Ctrl+O.
  • 끌어 놓기: 파일을 Papy 창으로 끌어다 놓습니다.
  • 더블클릭: 설치하면 PDF·HWP·HWPX·DOCX·DOC 파일을 Papy 로 열 수 있습니다.
  • 최근 문서: 시작 화면에서 다시 엽니다. 목록은 내 컴퓨터에만 저장되고 언제든 지울 수 있습니다.
  • 암호 문서: 암호가 걸린 PDF·HWP 는 암호를 물어봅니다. 암호는 저장하지 않습니다.

Papy 는 사용자가 직접 고른 파일만 읽습니다. 다른 폴더를 뒤지거나 파일을 어딘가로 올리지 않습니다.

편집 모드 v0.3.0

도구 막대의 편집 버튼 또는 Ctrl+E 로 보기 모드와 편집 모드를 오갑니다. HWP·HWPX·DOCX·DOC 는 워드프로세서처럼 고칩니다.

고급 편집 (HWP·HWPX)

편집 모드의 서식 막대 오른쪽 고급 편집을 누르면 표·셀, 그림·개체, 머리말·꼬리말, 각주, 찾아 바꾸기까지 고칠 수 있는 편집기가 열립니다. 적용을 누르면 문서에 반영되고, 저장은 평소처럼 Ctrl+S 로 합니다. 편집기도 인터넷 없이 동작합니다.

PDF 편집 v0.3.0

PDF 를 편집 모드로 바꾸면 도구 막대가 나옵니다.

  • 형광펜·밑줄·취소선: 도구를 고르고 글자 위를 끕니다.
  • 펜: 자유롭게 그립니다. 색과 굵기를 고를 수 있습니다.
  • 텍스트 상자·메모: 원하는 곳을 클릭하고 입력합니다(한글 가능).
  • 쪽 편집: 쪽 회전·앞뒤로 옮기기·삭제.
  • 되돌리기는 Ctrl+Z, 도구 해제는 Esc.

PDF 에 이미 있는 글자를 고쳐 쓰는 기능은 아직 없습니다.

저장·변환 v0.3.0

  • 저장 Ctrl+S: 원래 파일에 덮어씁니다. 저장 중 문제가 생겨도 원본이 깨지지 않게 임시 파일에 먼저 씁니다.
  • 다른 이름으로 저장 Ctrl+Shift+S: 새 위치와 형식을 고릅니다.
  • 내보내기: 도구 막대의 내보내기 메뉴에서 다른 형식으로 저장합니다.
  • 저장하지 않은 변경이 있으면 화면에 표시되고, 닫을 때 저장할지 묻습니다.
