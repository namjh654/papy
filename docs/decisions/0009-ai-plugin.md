# 0009. AI 플러그인: 앱 안 대화창과 MCP 서버, Claude·ChatGPT·Gemini 연결

- 상태: **채택 (2026-11-13)**. 기능 방향과 연결 대상(3사 모두)은 사용자가 정했다. 사용자가 PPT 보다 먼저 만들기로 했고, v0.5.0 시험판으로 낸다.
- 관련: [0008 제품 순서](0008-product-order-and-engines.md), [개인정보 처리방침](../../website/privacy/index.html)

## 맥락

사용자는 Claude·ChatGPT·Gemini 같은 AI와 문서 작업을 연동하고 싶어 한다. 예를 들어 요약, 번역, 문장 다듬기, 표 정리, 형식 변환을 대화로 시킨다.

막히는 곳이 하나 있다. **구독 계정(Claude Pro·ChatGPT Plus·Gemini)의 로그인 토큰을 다른 앱이 가져다 쓰는 길은 공식적으로 없다.** 약관상 구독 로그인은 각 회사 앱 전용이다. 우회하면 사용자 계정이 막힐 수 있다. 그래서 다음 세 가지 길만 쓴다.

1. **사용자의 AI 앱이 Papy 를 부른다**(MCP). 사용자는 이미 내는 구독을 그대로 쓴다.
2. **Papy 가 AI 를 부른다**: 사용자가 넣은 API 키(쓴 만큼 요금)나 로컬 모델을 쓴다.
3. **Papy 가 사용자 PC 의 AI 에이전트를 부른다**(ACP). 그 에이전트는 사용자가 직접 로그인한 구독으로 돈다.

Papy 는 "오프라인 우선, 문서를 밖으로 보내지 않음"을 약속해 왔다. 그래서 AI 는 **기본 앱에 넣지 않고**, 켜는 사람만 설치하는 플러그인으로 둔다.

## 결정

### 1. 구조

```
Papy 앱 (기본 설치, AI·네트워크 코드 없음)
 ├─ 대화창 패널 (플러그인이 있을 때만 보임)
 └─ 엔진 + "Papy 도구" 실행기 (문서 읽기·찾기·고쳐 쓰기 제안·변환)
        ▲ stdio JSON-RPC
        │
papy-ai (플러그인, 별도 실행 파일)
 ├─ 대화 실행기 (에이전트 루프, 실시간 출력, 토큰 사용량 집계)
 ├─ 연결: Anthropic · OpenAI · Google Gemini (API 키) / Ollama (로컬) / ACP 에이전트
 └─ MCP 서버 모드: `papy-ai mcp` (Claude 데스크톱·ChatGPT·Gemini CLI 등이 부른다)
```

- **플러그인 분리:** 네트워크·AI 코드는 `papy-ai` 에만 둔다. 기본 앱은 지금처럼 문서를 밖으로 보내지 않는다.
- **도구 정의는 한 벌:** 앱 안 대화창과 바깥 AI 앱(MCP)이 같은 Papy 도구를 쓴다. 도구 정의는 `papy-ai` 에 두고, 실제 실행은 앱(대화창)이나 `papy-ai` 안의 엔진(MCP 단독 실행)이 한다.
- **MCP 실행 방식 두 가지:**
  - 단독: `papy-ai mcp` 가 엔진(`papy-core`)을 직접 링크해 디스크 파일을 연다. 앱이 꺼져 있어도 된다. 먼저 이것을 만든다.
  - 앱 연결(나중): 앱에 열려 있는 문서를 다룬다. 앱이 로컬 소켓(접속 토큰 필요)을 열고 `papy-ai mcp --attach` 가 그쪽으로 넘긴다.

### 2. Papy 도구 (처음 묶음)

| 도구 | 하는 일 | 확인 필요 |
|---|---|---|
| `list_documents` | 열린 문서 목록(앱 연결) 또는 허용한 폴더의 문서 | 아니오 |
| `document_info` | 형식, 쪽 수, 목차, 옮기지 못한 개체 수 | 아니오 |
| `read_text` | 쪽 범위의 글 | 외부 AI 로 보낼 때 문서마다 한 번 |
| `find_text` | 글자 찾기(쪽·위치) | 위와 같음 |
| `read_structure` | 문단·표(행·열·칸 글) 구조 | 위와 같음 |
| `propose_edit` | 바꿀 내용 제안(문단 바꾸기, 글 넣기·지우기, 글자·문단 서식). **바로 적용하지 않는다** | 사용자가 미리보기에서 적용 |
| `export` | 다른 형식으로 저장, PDF 내보내기(새 파일로만) | 저장 위치 확인 |
| `render_page` | 쪽 그림(그림을 볼 수 있는 모델용) | 외부 전송 확인 |

- **고쳐 쓰기는 제안만 한다.** AI 가 쪽·표 구조를 망가뜨리지 않게 도구를 작게 나눈다. 적용은 앱의 편집 기능(`Engine::edit`)으로 하고, 한 번에 되돌릴 수 있게 묶는다.
- **원본은 덮어쓰지 않는다.** 저장은 새 파일만 만든다. 사용자가 앱에서 직접 저장할 때만 원본에 쓴다.

### 3. AI 연결

| 연결 | 계정·요금 | 메모 |
|---|---|---|
| Anthropic Claude (API 키) | 쓴 만큼 API 요금 | Messages API, 도구 호출, 실시간 출력 |
| OpenAI ChatGPT (API 키) | 쓴 만큼 API 요금 | Responses API, 도구 호출 |
| Google Gemini (API 키) | 쓴 만큼 API 요금(무료 사용량 있음) | Gemini API, 함수 호출 |
| Ollama (로컬) | 무료 | 도구 호출을 지원하는 모델만. 문서가 밖으로 나가지 않으니 외부 전송 확인을 하지 않는다 |
| ACP 에이전트: Claude Code · Gemini CLI · Codex CLI | **사용자 구독** | 사용자가 설치하고 로그인한 에이전트를 Papy 가 ACP 로 부르고, Papy 도구는 MCP 로 넘긴다(Zed 편집기와 같은 방식). **만들기 전에 회사별 허용 범위를 다시 확인한다** |

- **API 키 보관:** OS 키체인에 저장한다(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service). 설정 파일이나 로그에는 남기지 않는다.
- **토큰 사용량:** 대화마다 입력·출력 토큰과 어림 요금을 보여 준다. 대화창 위쪽에 이번 대화 합계를 표시한다.
- **모델 목록:** 하드코딩하지 않고 각 API 의 모델 목록 요청으로 받는다. 기본값만 설정에 둔다.

### 4. 설치와 업데이트

- **설치:** 설정 → 확장 기능 → "AI 도우미 설치"를 누르면 같은 버전의 GitHub Release 에서 `papy-ai-<버전>-<대상>.tar.gz` 를 받아 앱 데이터 폴더에 푼다.
- **검증:** 받은 파일은 **ed25519 서명**으로 확인한다. 공개 키는 앱에 넣고, 서명은 CI 가 한다(minisign 방식, 무료). 체크섬만으로는 같은 곳에서 받은 값을 믿는 셈이라 서명을 쓴다.
- **버전:** 앱과 플러그인 버전은 같은 번호로 맞춘다. 맞지 않으면 다시 받으라고 안내한다.
- **지우기:** 플러그인 폴더와 키체인 항목, 대화 기록을 지운다.
- **MCP 등록 안내:** 설정 화면에서 Claude 데스크톱·Gemini CLI 등에 넣을 설정(실행 경로)을 복사해 준다.

### 5. 개인정보

- **외부 전송 확인:** 외부 AI 로 문서 내용을 처음 보낼 때 문서마다 확인 창을 띄운다. 창에는 어느 문서의 어느 부분이 어느 회사로 가는지 적는다. "이 대화에서 다시 묻지 않기"는 둘 수 있지만 "항상"은 두지 않는다.
- **대화 기록:** 내 기기에만 저장하고 지울 수 있다. 끌 수도 있다.
- **고지 수정:** 웹사이트 개인정보 처리방침과 FAQ 에 "AI 플러그인을 설치하고 직접 고른 경우에만 외부 AI 로 보냄"을 적는다. 기본 앱 문구는 그대로 둔다.

## 단계와 규모 (1인+AI, 대략)

| 단계 | 내용 | 규모 |
|---|---|---|
| 1 | `papy-ai` 뼈대와 Papy 도구, 단독 MCP 서버(stdio). Claude 데스크톱·Gemini CLI 로 확인 | 1~2주 |
| 2 | 앱 대화창(대화 표시, 실시간 출력, 제안 미리보기·적용·되돌리기, 토큰 사용량)과 Claude·ChatGPT·Gemini API 키 연결, 키체인 | 3~4주 |
| 3 | Ollama 연결 | 2~3일 |
| 4 | ACP: Claude Code·Gemini CLI·Codex CLI 연결(허용 범위 확인 뒤) | 1~2주 |
| 5 | 플러그인 설치 관리(받기·서명 확인·지우기), CI 빌드·서명, 외부 전송 확인 창, 웹 고지 | 1~2주 |
| 6 | 앱 연결 MCP(`--attach`, 열린 문서 다루기) | 1주 |

권장 순서: **1 → 2 → 5 → 3 → 4 → 6.** 5(설치 관리)가 있어야 사용자에게 내놓을 수 있다. 그래서 2 다음에 둔다.

## 대안

| 안 | 버린 이유 |
|---|---|
| 구독 계정 로그인(OAuth)을 Papy 가 직접 처리 | 공식 경로가 없고 약관 위반이라 계정이 막힐 수 있다 |
| AI 를 기본 앱에 넣기 | "문서를 밖으로 보내지 않음" 약속과 부딪친다. 기본 설치가 커지고, AI 를 쓰지 않는 사람에게도 네트워크 코드가 들어간다 |
| 대화창 없이 MCP 서버만 | 바깥 AI 앱이 있어야만 쓸 수 있다. 사용자는 앱 안에서 대화하기를 원했다 |
| Node·Python 으로 플러그인 작성 | 실행기를 따로 깔아야 한다. 엔진(`papy-core`)을 바로 링크할 수 있는 Rust 가 낫다 |
| 체크섬만으로 플러그인 검증 | 같은 출처의 값을 믿는 것이라 출처가 바뀌면 막지 못한다. ed25519 서명은 무료다 |

## 결과

- 기본 앱의 크기와 개인정보 약속은 그대로다.
- 사용자는 셋 중 고를 수 있다:
  - 구독(MCP·ACP)
  - API 키(Claude·ChatGPT·Gemini)
  - 무료 로컬 모델(Ollama)
- 문서 고쳐 쓰기는 항상 미리보기와 되돌리기를 거친다.
- 라이선스: PolyForm Noncommercial 이라 회사에서 AI 기능을 쓰는 것도 상업 이용 판단을 따른다. 별도 조항은 두지 않는다.
- 남은 확인:
  - ACP 로 각 회사 에이전트를 부르는 것이 허용되는지(4단계 전에)
  - 각 API 의 현재 도구 호출 형식과 모델 목록 요청(2단계 시작 때 공식 문서로)
