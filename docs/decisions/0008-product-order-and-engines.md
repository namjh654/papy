# 0008. 제품 순서와 형식별 엔진 구조

- 상태: **승인 (2026-11-11)** — 사용자 결정
- 관련: [0004 HWP 엔진](0004-hwp-engine.md), [0005 rhwp-studio](0005-rhwp-studio-editor.md), [0007 XLSX·PPTX](0007-xlsx-pptx.md),
  [이어서 할 일](../development/next-steps.md)

## 결정

1. **순서.** 문서 3종을 먼저 끝낸다. 문서 3종은 한글(HWP·HWPX), 워드(DOC·DOCX), PDF다. 이것을 안정화한 뒤 **서비스를 배포한다**.
   그다음 PPT·PPTX를, 그다음 XLS·XLSX를 단계별로 더한다.
2. **엔진 구조.** 조판 엔진은 rhwp **하나**로 두고 형식마다 가져오기 필터와 호환 규칙을 얹는다(LibreOffice·한컴·폴라리스와 같은 방식).
   - HWP·HWPX: rhwp 그대로.
   - DOC·DOCX: Papy 필터(`papy-office`)가 rhwp 문서로 옮긴다. 다른 형식에서 온 문서는 Word 호환 규칙으로 조판한다
     (rhwp `foreign_layout` 프로필과 패치 0018·0022 등). Word 조판 엔진을 새로 만들지 않는다.
     새로 만들면 1인+AI 기준으로 보기만 6개월~1년이고, rhwp의 한글 조판(글꼴 재기·줄바꿈)을 다시 만들어야 한다.
   - PDF: PDFium(보기). 문서 3종을 PDF로 내보낼 때는 rhwp를 쓴다.
   - PPT·PPTX(나중): ADR 0007 1안. 슬라이드 하나를 한 쪽으로, 도형을 쪽 기준 개체로 옮겨 rhwp로 그린다. PDF 내보내기를 지원한다.
   - XLS·XLSX(마지막): 쪽 모델에 맞지 않아 별도 시트 엔진을 둔다(ADR 0007, IronCalc 우선). **PDF 내보내기는 지원하지 않는다.**
   - 상용 SDK·LibreOffice·ONLYOFFICE는 쓰지 않는다. 비용, PolyForm NC와의 궁합(AGPL), 크기(수백 MB), 모바일 문제 때문이다.
3. **변환 오차는 고지한다.** 한글과 Word는 조판 규칙이 달라서, 형식을 바꾸면 배치·쪽 수가 달라질 수 있다.
   - 앱은 형식을 바꿔 저장하거나 다른 형식 문서를 열 때 이 점을 알린다. 옮기지 못한 요소 수(`dropped_objects`)는 지금처럼 보여 준다.
   - 왕복 쪽 수를 원본과 **똑같이 맞추는 작업은 하지 않는다**. 고치는 대상은 내용 손실, 깨진 배치(겹침·잘림·빈 쪽), 크래시, rhwp 자체 버그다.
4. **rhwp 위험 관리.** rhwp는 개인 프로젝트라 불안정할 수 있다.
   - 버전을 고정하고 패치(`engine/patches/rhwp`)로 고친다.
   - 올릴 때마다 문서 모음 회귀 시험을 돌린다(rhwp 샘플·POI·시험지 12개).
   - 고친 것은 업스트림에 PR로 돌려준다.
   - MIT라 멈추면 포크해서 잇는다.

## 형식별 예상 규모 (1인+AI, 대략)

| 형식 | 방식 | 첫 보기 | 쓸 만한 수준 | 편집 | 앱 크기 증가 |
|---|---|---|---|---|---|
| PPTX | rhwp 쪽 위 슬라이드 개체 | 2~4주 | 2~3개월 | 글상자 +1~2개월 | +1~3MB |
| PPT(97–2003) | 이진 파서 새로 | PPTX 뒤 +1~2개월 | | | 작음 |
| XLSX | IronCalc + 격자 조각 그리기 | 3~6주 | 2~3개월 | 칸 편집 +1~2개월 | +3~5MB |
| (참고) Word 자체 엔진 | 채택 안 함 | 1~2개월 | 6개월~1년 | +수개월 | +3~8MB |

## 대안

| 안 | 버린 이유 |
|---|---|
| 형식마다 자체 조판 엔진 | Word·PPT·Excel 엔진을 모두 새로 만들어야 하고, 한글 조판을 형식마다 다시 만든다. 1인 규모를 넘는다 |
| LibreOffice(LOK) | MPL이라 라이선스는 맞지만 수백 MB이고 모바일이 무겁다. 내부 모델도 ODF라 Word 충실도 이득이 작다 |
| ONLYOFFICE | AGPL(PolyForm NC와 결합 불가). 상용 라이선스는 비용이 든다 |
| 상용 SDK(Aspose·Apryse·Syncfusion 등) | 비용과 배포 조건. 편집 화면은 주지 않는다 |
