# Word 문서 (DOCX · DOC)

Word 문서는 `papy-office` 가 HTML(문서 구조)과 부가 정보(머리말·꼬리말·각주·도형·제목)로 바꾸고, `papy-hwp` 가 rhwp 문서에
붙여넣어 조판한다. 그래서 보기·편집·찾기·PDF 내보내기는 HWP 와 같은 엔진을 쓴다. 저장은 `papy-office` 의 DOCX 쓰기,
또는 rhwp 의 HWP·HWPX·PDF 쓰기로 한다. 옮기지 못한 요소 수는 문서 정보(`dropped_objects`)로 알리고, 앱이 사용자에게 보여 준다.

## DOCX

| 요소 | 읽기 | 쓰기(DOCX 저장) |
|---|---|---|
| 본문 글자·글자 모양·문단 모양 | ○ | ○ |
| 쪽 크기·여백·머리말 자리·다단 | ○ — 구역이 여럿이면 문단이 가장 많은 구역 것 | ○ — 구역 안에서 단 정의가 바뀌면(1단 ↔ 2단 등) 이어지는 구역(`w:type continuous`)으로 나누고, 한글 구역은 새 쪽 구역으로 |
| 문단 앞뒤 간격·줄 간격(배수·고정)·들여쓰기/내어쓰기, 자간·장평 | ○ — 기본 문단 스타일(Normal)도 따른다 | ○ — 한글 배수 줄 간격은 Word 에 "최소(글자 크기 × %)"로 쓰되 130% 보다 좁고 그림·수식이 없는 문단은 "고정"으로(Word 가 글꼴 고유 높이로 늘리지 않게) 쓰고, Papy 가 다시 열 때는 원래 % 로(`papy:linePercent`, Word 는 무시) |
| 표(가로·세로 병합, 칸 너비, 칸 테두리·배경, 세로 정렬, 행 높이, 칸 안쪽 여백, 왼쪽 자리) | ○ — 쪽보다 긴 행은 다음 쪽으로 이어진다. 표 안 표의 글도 칸 너비로 접는다 | ○ — 칸 경계가 행마다 다른 한글 양식 표도 열 격자로 푼다. 행 높이는 칸 테두리 굵기를 뺀다(Word 는 행 높이에 테두리를 더한다) |
| 나란히 놓인 표(한글: 한 문단에 글자처럼 놓은 표 여럿) | — | 테두리 없는 한 줄 표의 칸에 하나씩 |
| 쪽·종이 기준 떠 있는 표(쪽 아래 결재란 등) | ○(`w:tblpPr`) | ○ |
| 그림(PNG·JPEG·GIF·BMP), 글자처럼·떠 있는 그림 | ○ | ○ — BMP 는 PNG 로 줄여 넣는다 |
| 도형(사각형·타원·선·글상자), 묶음 도형 | ○ — 묶음은 안의 도형·그림·차트를 같은 자리에 푼다 | ○ — 다각형·곡선·호는 꼭짓점 경로(`a:custGeom`), 묶음은 Word 그리기 묶음(`wpg:wgp`) |
| 떠 있는 그림 | ○ | ○ — 기준·위치·글 배치를 지킨다 |
| 수식(한글) | — | 그림(PNG)으로, 기준선을 맞춘다 |
| 양식 개체(한글: 선택 상자·라디오 단추·단추·입력 상자) | — | 글로(☑ ☐ ◉ ○ [단추], 입력 내용) |
| 차트(막대·선·영역·원·도넛·분산) | ○ — 캐시된 값으로 그림을 그려 넣는다(편집은 안 됨) | 그림으로 |
| 머리말·꼬리말(모든 쪽·짝수/홀수 쪽) | ○ — 짝수 쪽 것은 `evenAndOddHeaders` 가 켜졌을 때만 | ○ |
| 첫 쪽 다른 머리말·꼬리말(`titlePg`) | 첫 쪽에서 기본 것을 감춘다. 첫 쪽 전용 내용은 옮기지 못한 요소로 센다 | `titlePg` 로 첫 쪽 감추기를 지킨다 |

| 쪽 번호(머리말·꼬리말 `PAGE`·`NUMPAGES` 필드) | ○ — 쪽마다 맞는 번호로 | ○ — 한글 쪽 번호 위치·번호 넣기를 필드로 |
| 각주·미주 번호 모양(앞뒤 글자·위 첨자·번호 형식) | — | ○ — 시험지의 "문1)" 같은 미주 번호 |
| 메모·변경 추적 | ○ — 메모 목록(쓴 사람·글·쪽), 변경 추적은 받아들인 상태로 보이고 수를 알린다 | — |
| 글꼴 표(`fontTable.xml`) | — | ○ — 명조·고딕 계열과 한글 문자 집합, 대체 글꼴(바탕·맑은 고딕) |
| 쪽 나누기(`w:br type=page`, `pageBreakBefore`) | ○ | ○(`pageBreakBefore`) |
| 단 나누기(`w:br type=column`) | ○ | ○ |
| 탭(문단 탭 위치·종류·채움, 기본 탭 간격) | — (기본 간격으로 잰다) | ○(`w:tabs`, `w:defaultTabStop`) |
| 칸 대각선(`w:tl2br`·`w:tr2bl`) | — (그리지 않는다) | ○ |
| 목차(제목 스타일·개요 수준) | ○ | ○ |
| VML 개체(`w:pict`·`w:object`, OLE 포함), 읽지 못한 그리기(SmartArt 등) | 옮기지 못한 요소로 센다 | — |
| 수식·메모·변경 내용 추적 | 글자만 옮기거나 빠진다(따로 세지 않는다) | — |

알려진 한계
- 한글 → DOCX 는 조판 방식이 달라 쪽 수가 다를 수 있다(rhwp 샘플 66개를 Word 로 연 쪽 수 기준 평균 오차 HWP 약 19%·HWPX 약 14%, [test-corpus.md](test-corpus.md). 남은 차이의 큰 몫은 설치되지 않은 한글 글꼴을 대체 글꼴로 재며 생기는 줄 높이·줄바꿈 차이). 2단 문서에서 왼쪽 단이 조금이라도 넘치면 뒤따르는 단 나누기가 한 단씩 밀려 쪽이 크게 늘 수 있다. 문단 탭 위치는 Papy 로 다시 열 때 아직 읽지 않는다(기본 탭 간격으로 잰다). 쪽 높이에 꼭 맞춘 양식 표가 여럿인 문서, 문단 기준으로 아래로 내려 놓은 표는 표가 다음 쪽으로 밀릴 수 있다. 쪽 아래에 붙인 결재란(쪽 기준 표)은 Word 에서는 제자리지만 Papy 로 다시 열면 다음 쪽으로 넘어갈 수 있다.
- 누름틀 안내문(인쇄되지 않는 자리표시 글)은 옮기지 않는다. 겹친 묶음 안 개체의 회전은 둘러싼 상자로 근사한다.
- 저장 후 다시 열면 머리말·꼬리말 글이 글 꺼내기 순서에 섞여 나오는 문서가 있다(조판 결과는 같다).

## DOC (Word 97–2003)

`papy-office::doc_to_html` 이 MS-DOC 이진 형식(FIB·조각표·CHPX/PAPX·스타일·글꼴 표)을 직접 읽는다(`cfb` crate).

| 요소 | 상태 |
|---|---|
| 본문 글자(유니코드·코드 페이지 조각), 굵게·기울임·밑줄·취소선·색·글꼴·크기, 숨긴 글자·지운 글자 빼기 | ○ |
| 문단 정렬·개요 수준, 쪽 나누기, 단 나누기, 구역 나누기 종류(이어서·새 단·새 쪽) | ○ |
| 표(중첩 포함, 병합, 칸 너비, 테두리 — 큰 PAPX 포함) | ○ |
| 글자처럼 넣은 그림(PNG·JPEG·TIFF, DIB → BMP) | ○ |
| 각주·미주 | ○ |
| 머리말·꼬리말(첫 쪽 감추기 포함) | ○ |
| 필드 | 결과 글자만(오래된 쪽 번호 결과가 그대로 보일 수 있다) |
| 목록 | 글머리표 "•" 로 |
| 쪽 크기·여백·다단(글이 가장 긴 구역) | ○ |
| 떠 있는 도형(사각형·타원·선, 채우기·선 색)·글상자·그림·묶음 도형 | ○ — 기준·위치·글 배치(위아래·어울림·글 앞/뒤)를 지킨다 |
| OLE 개체(수식 등)·EMF/WMF 그림 | 미리보기 그림으로(EMF·WMF → SVG) |
| Word 6/95(nFib < 0xC1) | `UnsupportedFormat` |
| 암호 걸린 DOC | ○ — RC4(버전 1.1)·RC4 CryptoAPI 를 암호로 푼다. 암호가 없거나 틀리면 `PasswordRequired`, XOR 난독화는 `PasswordRequired` |

DOC 는 같은 형식으로 쓰지 않는다. 데스크톱은 저장할 때 DOCX 를 먼저 권하고, 모바일은 DOC 를 보기·PDF 내보내기 전용으로 연다.
