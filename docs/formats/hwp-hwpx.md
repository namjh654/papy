# HWP 5.x 와 HWPX

| 항목 | HWP 5.x | HWPX |
|---|---|---|
| 컨테이너 | OLE 복합 문서(CFB) — 스트림·스토리지 트리 | ZIP (첫 항목 `mimetype` = `application/hwp+zip`, OCF 유사) |
| 본문 | 바이너리 레코드(태그 ID·레벨·크기 헤더) 스트림, 섹션별 zlib 압축 | XML (`Contents/header.xml`, `Contents/section*.xml`) |
| 규격 | 한컴 공개 문서 "한글 문서 파일 형식 5.0" | KS X 6101 (OWPML) |
| 배포용·암호 | 배포용 문서 암호화, 문서 암호 | 암호화 지원(ZIP 내부 암호화 항목) |
| 개체 | 그림·OLE·수식(스크립트)·차트·양식 컨트롤 | 같은 개념을 XML 요소로 |
| Papy 판별 | `papy-core::detect_format` → `CompoundFile` (구형 DOC/XLS/PPT 와 구분은 `FileHeader` 스트림 확인 필요) | → `Hwpx` |

## 구현 위험

1. **레이아웃 재현**: 파일에는 조판 결과(줄 나눔·쪽 나눔)가 일부만 있다. 줄 배치·쪽 나눔을 엔진이 다시 계산하므로 한컴오피스와 쪽 수가 달라질 수 있다.
2. **폰트**: 함초롬·HY 계열 등 한컴/MS 폰트는 재배포할 수 없다. 메트릭이 다른 대체 폰트로 줄바꿈이 달라진다 → OFL 폰트 폴백 표와 차이 표시 필요.
3. **개체 다양성**: 표 셀 병합·쪽 넘김 표, 글상자, 수식, 차트, 각주·미주, 머리말/꼬리말, 바탕쪽, 다단.
4. **HWP 5.x 바이너리 파싱 안전성**: 레코드 크기·중첩 깊이·압축 해제 크기를 신뢰할 수 없다 → 상한·fuzz 테스트 필수(기획서 6.2).
5. **HWPX ZIP 안전성**: 압축 폭탄, 경로 탈출(`../`) 항목, 과도한 항목 수.
6. **버전 차이**: 한글 2002~2024 저장본, 일부 비표준 저장(타 프로그램 생성 HWPX).
7. **저장**: 원본에 있던 알 수 없는 레코드·XML 확장을 보존하지 못하면 정보 손실 → 편집 단계에서 왕복(open→save→open) 테스트.
