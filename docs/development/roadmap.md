# 단계별 PoC·MVP 완료 기준

기획서 8장을 구체화한다. 각 단계는 작은 PR 로 나누고, 완료 기준을 테스트로 확인한 뒤 다음 단계로 간다.

| 단계 | 산출물 | 완료 기준 | 상태 |
|---|---|---|---|
| 0. 설계·조사 | 엔진 후보 비교(ADR 0003·0004), API 초안, 코퍼스 구성안, 라이선스 정책 | 엔진 선택 승인 | **완료** (2026-11-03 승인) |
| 1. Rust Core | `Engine`/세션 핸들, 오류 코드, 상한, 취소, 포맷 판별, 어댑터 계약 | 단위 테스트(가짜 어댑터로 세션·상한·취소·동시성) + rustdoc | **완료** |
| 2a. PDF PoC | `papy-pdf` PDFium 어댑터 | 코퍼스 PDF 열기·렌더·텍스트, 손상 파일이 정해진 오류로 끝남, 첫 페이지 표시 시간 측정 | 어댑터 완료(생성 PDF 테스트). 코퍼스·시간 측정 남음 |
| 2b. HWPX PoC | `papy-hwp` rhwp 어댑터 | 코퍼스 HWPX 열기·렌더, 미지원 요소 표시, HWP 5.x 게이트 판단 자료 | 어댑터 완료(HWPX·HWP 5.x, 생성 문서 테스트). 코퍼스·미지원 요소 표시 남음 |
| 3. Desktop MVP | 파일 열기(선택·드래그), 페이지 이동·확대/축소, 문서 정보, 최근 문서 | Windows·macOS·Linux 에서 같은 코퍼스로 수동·자동 확인 | 기능 구현, 실제 문서로 OS별 수동 확인 남음 |
| 4. 안정화 | 성능 리포트, fuzz, 장시간 테스트, 서명·릴리스 | 기획서 6.1 목표 가설 대비 측정값, 크래시 0 | — |
| 5. KMP | Android/iOS 브리지(`papy-ffi`) | 같은 코퍼스 기능·렌더 검증 | **1단계 완료**(2026-11-04, [ADR 0006](../decisions/0006-mobile-bridge.md)): UniFFI 연결, 보기 전용(HWP·HWPX·DOCX 는 Rust, PDF 는 운영체제), 최근 문서·암호·글자 보기. 에뮬레이터·시뮬레이터 확인. **2단계**: 확대 후 다시 그리기, 문단 편집·되돌리기·저장, Android 릴리스 준비(R8·16KB·ABI·권한). 템플릿 모듈 정리 완료(APK 42.9→40.2MB, dex 6.8→3.4MB). 앱 안 라이선스 화면 남음 |
| 6. 편집 | PDF 주석·쪽 편집, HWP/HWPX 본문 편집, 저장·변환 | 저장 후 재열기·왕복 테스트 | **1차 완료**(2026-11-03): 엔진 테스트로 저장→재열기 확인. 표 셀·그림 편집, 실제 문서 코퍼스 남음 |
| 6b. DOCX | DOCX ↔ 문서 구조 변환기(rhwp 배치·편집 재사용) | DOCX 열기·편집·DOCX 저장, HWP/HWPX/PDF 와 상호 변환 | **1차 완료**(2026-11-03): 본문·서식·표(병합)·그림(PNG·JPEG·GIF·BMP, 읽기·쓰기). 못 옮긴 도형 수를 앱이 알림. **2차**(2026-11-03): 머리말·꼬리말(모든 쪽·짝수/홀수 쪽)·본문 각주·번호 목록(번호 글자로) 읽기·쓰기. 도형·미주·표 안 각주·첫 쪽 머리말 남음 |
| 6c. 고급 HWP 편집 | rhwp-studio 를 앱에 넣어 "고급 편집"(ADR 0005) | 표·개체·머리말·각주·찾아 바꾸기 | PoC 완료(macOS). Windows·Linux 창·한글 입력기 확인 남음 |
