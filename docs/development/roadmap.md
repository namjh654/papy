# 단계별 PoC·MVP 완료 기준

기획서 8장을 구체화한다. 각 단계는 작은 PR 로 나누고, 완료 기준을 테스트로 확인한 뒤 다음 단계로 간다.

| 단계 | 산출물 | 완료 기준 | 상태 |
|---|---|---|---|
| 0. 설계·조사 | 엔진 후보 비교(ADR 0003·0004), API 초안, 코퍼스 구성안, 라이선스 정책 | 엔진 선택 승인 | **완료** (2026-11-03 승인) |
| 1. Rust Core | `Engine`/세션 핸들, 오류 코드, 상한, 취소, 포맷 판별, 어댑터 계약 | 단위 테스트(가짜 어댑터로 세션·상한·취소·동시성) + rustdoc | **완료** |
| 2a. PDF PoC | `papy-pdf` PDFium 어댑터 | 코퍼스 PDF 열기·렌더·텍스트, 손상 파일이 정해진 오류로 끝남, 첫 페이지 표시 시간 측정 | 어댑터 완료(생성 PDF 테스트). 2026-11-04: 문서 모음 회귀(PDF 63개) 기준값 통과, 첫 쪽 표시 시간 중앙값 3 ms·99% 26 ms |
| 2b. HWPX PoC | `papy-hwp` rhwp 어댑터 | 코퍼스 HWPX 열기·렌더, 미지원 요소 표시, HWP 5.x 게이트 판단 자료 | 어댑터 완료(HWPX·HWP 5.x, 생성 문서 테스트). 2026-11-04: rhwp 샘플 1,268개 회귀 기준값·손상 파일 테스트, HWP 3.x(보기 전용)·비표준 HWPX 열기. 2026-11-04: 목차(개요 문단)·글자 찾기, 그리지 못한 개체(차트·OLE 자리표시, 데이터 없는 그림)를 쪽마다 알림(데스크톱·모바일), 첫 쪽 표시 시간 측정(HWP/HWPX 중앙값 15~19 ms) |
| 3. Desktop MVP | 파일 열기(선택·드래그), 페이지 이동·확대/축소, 문서 정보, 최근 문서 | Windows·macOS·Linux 에서 같은 코퍼스로 수동·자동 확인 | 기능 구현, 실제 문서로 OS별 수동 확인 남음 |
| 4. 안정화 | 성능 리포트, fuzz, 장시간 테스트, 서명·릴리스 | 기획서 6.1 목표 가설 대비 측정값, 크래시 0 | **진행 중**(2026-11-04): HWP 쪽 그리기 2~6배 빨라짐(글꼴 데이터 매핑 재사용, 쪽당 약 160→45 ms), 문서 모음 1,268개·16,320쪽 크래시 0, 손상 파일 168가지, 무작위 손상 반복(fuzz 대용) 17만 번·장시간 반복 300번 실패 0·누수 없음. 큰 표 문서 조판 10~15배 빨라짐(rhwp 패치, 161쪽 문서 열기 70→4.5초). 서명·릴리스 남음 |
| 5. KMP | Android/iOS 브리지(`papy-ffi`) | 같은 코퍼스 기능·렌더 검증 | **1단계 완료**(2026-11-04, [ADR 0006](../decisions/0006-mobile-bridge.md)): UniFFI 연결, 보기 전용(HWP·HWPX·DOCX 는 Rust, PDF 는 운영체제), 최근 문서·암호·글자 보기. 에뮬레이터·시뮬레이터 확인. **2단계**: 확대 후 다시 그리기, 문단 편집·되돌리기·저장, Android 릴리스 준비(R8·16KB·ABI·권한). 템플릿 모듈 정리 완료(APK 42.9→40.2MB, dex 6.8→3.4MB). **3단계**: 커서 편집·글자 모양·서식 지키는 문단 바꾸기·PDF 로 내보내기. **4단계**: 표 칸·글상자 안 편집, 표 넣기·행열·합치기, 그림 넣기·크기·지우기, 앱 안 오픈소스 라이선스 화면. **5단계**: 칸 안 선택·글자 모양, 그림 바로 뒤 커서. **6단계**(2026-11-04): 목차·찾기·그리지 못한 개체 알림, 칸 안 위·아래 줄 이동(다른 칸·표 밖으로) |
| 6. 편집 | PDF 주석·쪽 편집, HWP/HWPX 본문 편집, 저장·변환 | 저장 후 재열기·왕복 테스트 | **1차 완료**(2026-11-03): 엔진 테스트로 저장→재열기 확인. 표 셀·그림 편집, 실제 문서 코퍼스 남음 |
| 6b. DOCX | DOCX ↔ 문서 구조 변환기(rhwp 배치·편집 재사용) | DOCX 열기·편집·DOCX 저장, HWP/HWPX/PDF 와 상호 변환 | **1차 완료**(2026-11-03): 본문·서식·표(병합)·그림(PNG·JPEG·GIF·BMP, 읽기·쓰기). 못 옮긴 도형 수를 앱이 알림. **2차**(2026-11-03): 머리말·꼬리말(모든 쪽·짝수/홀수 쪽)·본문 각주·번호 목록(번호 글자로) 읽기·쓰기. **3차**(2026-11-04): 도형(사각형·타원·선·글상자) 읽기·쓰기, 목차(제목 스타일·개요 수준 읽기·쓰기), 묶음 도형(안의 도형을 풀어 같은 자리에), 미주 읽기·쓰기. **4차**(2026-11-05): 차트(그림으로)·묶음 안 그림·표 안 각주·첫 쪽 머리말 감추기(쓰기 포함)·칸 너비·쪽 나누기, 짝수 쪽 머리말 설정 지키기, 쪽보다 긴 표 행을 다음 쪽으로. Apache POI 문서 모음 회귀 기준값([word.md](../formats/word.md)). **5차**(2026-11-05, v0.3.1): 쪽 크기·여백·다단, 문단 간격·줄 간격·들여쓰기·자간, 칸 테두리·배경·세로 정렬·행 높이 읽기·쓰기, 표 안 표 줄 나누기, 한글 → DOCX 에 수식(그림)·양식 개체(글)·묶음 도형·다각형·곡선·호·떠 있는 그림 |
| 6d. DOC | Word 97–2003 읽기(MS-DOC 직접 해석) | DOC 열기·편집·DOCX/HWP/HWPX/PDF 로 저장 | **1차 완료**(2026-11-05): 본문·글자/문단 모양·표(중첩·병합)·그림·각주·미주·머리말/꼬리말·쪽 나누기. 데스크톱·모바일 연결(모바일은 보기·PDF 내보내기). POI DOC 159개 중 131개 열림(나머지는 Word 6/95·손상·암호). 떠 있는 도형·OLE·암호 DOC 남음 |
| 6e. PDF 변환 | HWP·HWPX·DOCX·DOC → PDF | 문서 모음 전체 PDF 내보내기 실패 0 | **완료**(2026-11-05): 문서 모음 1,495개 점검(PDF 1,447개 내보냄, 실패 0). 깨진 그림 하나로 문서 전체가 실패하던 17개 해결, PDF 내보내기 쪽당 약 700 → 50 ms(동시 12). v0.3.1: PDFium(Chrome·Papy)에서 글 찾기·복사가 되게 쪽 그림 배율을 바로잡음(패치 0006) |
