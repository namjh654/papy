- **D2 iOS framework**: (가) `Core` 이름 유지 + 분리 모듈 전부 `export()` → Swift 코드·타입 이름 변화 없음 (나) `Shared` umbrella 로 개명 → 모든 Swift `import Core` 수정
- SKIE 노출: `export()` 한 모듈의 타입은 지금과 같은 이름(`LoginViewModel`, `AppError`, `ErrorCode` …). export 하지 않은 모듈의 타입이 공개 API 에 나오면 모듈 접두어가 붙어 Swift 코드가 깨진다.
