## 정리 — Windows 에서 확인할 것 / 서버 확인 필요 / 남은 일

**Windows 에서 확인할 것**
- `scripts/orca.sh check`(Android + templateCheck) — mac 에서 바뀐 것: orca.sh 의 iOS 빌드 방식(scheme), 권한 deny 추가(DEC-024: `git reset --hard`·`git branch -D` 차단 — orca.sh merge 실패 안내도 revert 로)
- 원격 이름: 이 mac 은 origin=GitHub, gitlab=사내로 바꿨다(DEC-062). Windows 도 origin 이 GitHub 인지 `git remote -v` 확인
- Android Studio 에서 새 화면(탭·목록·설정·웹뷰·업데이트 안내) 한 번 실행, JDK/데몬(Corretto 21) 그대로인지

**서버 확인 필요 (모두 가정 — DEC-055, 계약 표 docs/template-setup.md §2)**
- 로그인 요청 필드(`id` vs `username`), 응답 토큰 필드
- 토큰 재발급 `POST /api/auth/refresh {refreshToken}` → `{accessToken, refreshToken?}` 유무·경로(없으면 env `auth.refreshPath` 비움)
- 목록 페이징 `GET …?page=N` → `{items, nextPage}`
- 버전 확인 `GET /api/app/version?platform=` → `{minimumVersion, latestVersion, storeUrl}`
- 푸시 토큰 등록/해제, 로그아웃 서버 호출 필요 여부
