# DECISIONS — 결정 기록

> 결정은 **ocra 에서만** 기록한다: `scripts/orca.sh decide "내용" --area 영역 --why "근거"`.
> 워크트리(android/ios)는 `.orca/notes/<role>.md` 에 `[결정제안]` 으로 남기고 ocra 가 옮긴다.
>
> 상태 흐름
> - 자동 모드: `검토대기` 로 기록하고 작업은 계속 진행 → 최종 보고(`orca.sh report`)에서 종합 검토 → `확정` 또는 `재작업`
> - 수동 모드: `승인대기` 로 기록하고 **사용자 승인(`approve`) 전에는 해당 결정에 의존하는 작업 중단**
> - `재작업` → 수정 후 `reopen` → 다시 `검토대기`
>
> 아직 결정되지 않은 아키텍처 항목(D1~D12)은 [PROGRESS.md §5](../PROGRESS.md) 에 있다. 결정되면 여기에 DEC 로 옮긴다.
